# Wind Generation Forecast Monitor

A web app to compare UK national wind power forecasts with actual generation.

> Status: the frontend scaffold is ready. Data and charts are coming soon.

## Tech stack

- Frontend: React + Vite
- Backend: Python (coming)
- Docker

## Folder structure

```
.
├── frontend/            # React app (Vite)
│   ├── index.html       # Main HTML page
│   ├── package.json     # Frontend packages and scripts
│   ├── vite.config.js   # Vite settings
│   └── src/             # React code
│       ├── main.jsx     # App entry point
│       ├── App.jsx      # Main page
│       └── index.css    # Styles
├── backend/             # Python backend (coming)
│   ├── app/             # Backend code
│   └── tests/           # Backend tests
├── Dockerfile           # Docker setup (placeholder)
├── vercel.json          # Vercel build settings
└── README.md            # This file
```

## Run locally

You need [Node.js](https://nodejs.org/) installed.

```bash
cd frontend
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.
