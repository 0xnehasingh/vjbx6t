# Wind Generation Forecast Monitor

A web app to view national wind power forecasts next to actual generation, and to measure forecast accuracy.

> Status: project scaffold. Implementation in progress.

## Tech stack
- Frontend: React
- Backend: Python
- Containerised with Docker

## Project structure
```
.
├── frontend/          # React app
│   ├── public/
│   └── src/
├── backend/           # Python API
│   ├── app/
│   └── tests/
├── Dockerfile

```
